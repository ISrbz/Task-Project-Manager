# Мениджър на задачи и проекти ✈️
### Функционалност
- Създаване на задача/проект - поставяне върху линията на времето
- Проверка на статуса на всички задачи в проект - ако една е започната проектът се означава като започнат; ако всички са завършени проектът се означава като завършен
- Краен срок тази седмица - увеличава приоритета
- Краен срок днес - увеличава приоритета още повече
- Филтриране по (приоритет, краен срок, проект, статус) - показва задачите, отговарящи на дадените критерии
- Сортиране по (приоритет, краен срок, статус)
- Показване на всички - линия на времето
- Показване на детайли за задача/проект
